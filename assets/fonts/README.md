# Fonts

Bundled so that subtitles and the end card render the same on every machine.

| File | Family | Used for |
| --- | --- | --- |
| `NotoSans-Regular.ttf`, `NotoSans-Bold.ttf` | Noto Sans | English subtitles, end card |
| `NotoSansEthiopic-Regular.ttf`, `NotoSansEthiopic-Bold.ttf` | Noto Sans Ethiopic | Amharic text on the end card |

Both families are copyright Google and licensed under the SIL Open Font License 1.1, which allows
redistribution with the licence included. The full copyright notice and licence text are in
